# herdr-manifold

A desktop client for Herdr, a terminal multiplexer for coding agents: the
workspaces, tabs and live panes of a Herdr session, and the agents in them
with their states, in a window of its own instead of the terminal UI. A
Visual Studio Code extension over the same core comes second.

Work in progress: nothing is implemented yet. What the client is going to do
is decided in [`specs/`](specs/README.adoc), starting with
[herdr-manifold#1 — purpose and stack](specs/herdr-manifold%231-purpose-and-stack/spec.adoc).
